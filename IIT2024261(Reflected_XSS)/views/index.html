Reflected Cross-Site Scripting (XSS)

Welcome to the Web Server Security demonstration for IIIT Allahabad. This lab demonstrates how unescaped user input causes reflected XSS, and how context-aware output encoding prevents it.

⚠️ 1. Vulnerable Route (/vulnerable)
Directly reflects input into the HTML response without escaping. Injected scripts execute in the browser. 🛡️ 2. Secured Route (/secure)
Sanitizes input with HTML entity encoding. Injected scripts are safely displayed as plain text.
